## The ruled method, compressed (full text in the artifact)

- **Seats — Ben's four-function minimum is operative canon:** GREEN =
  supported pro case (demonstration, not praise) · RED = adversarial
  problem finder · BLUE = answers Red, that is all · WHITE = the only
  seat that reads everything; aggregates, adjudicates, concludes.
- **Information flow (ruled):** Green ∥ Red run blind to each other;
  Blue reads the artifact + Red's memo ONLY (not a dispute-settler,
  never sees Green); White reads all.
- **The no-markers independence rule (ruled, and the sharpest upgrade
  over every prior version):** the plan's authors never write test
  points, charge sheets, or worked scenarios for reviewers — Ben:
  *"by writing in specific concerns for red to go after you're usurping
  part of its role without the independence."* A seat receives the plan,
  its justification, its aims, and a role description. Where a reviewer
  chooses to probe is part of the signal. Quality-bar conduct rules
  (findings must be demonstrated; zero findings is an acceptable
  outcome; suggested remedy required) survive — they are conduct, not
  direction.
- **Precondition — the artifact carries its own justification:**
  reviewers are fresh-context; if the plan's why lives in a chat they
  never see, they review a skeleton and White concludes from ignorance.
  Lay the philosophy/justification/aims into the document before the
  run (q1's §1.5 is the worked instance).
- **Machinery carried from the manuscript protocol, with receipts:**
  substantive/line tagging by dominant character · carry count (never
  win rate) as the diagnostic · ≤2-substantive-carries pass bar ·
  3–5 revise band (full vs targeted re-review) · 6+ step back ·
  targeted re-review statuses (RESOLVED / PARTIALLY / NOT
  RESOLVED–recursive / NEW PROBLEM IN REMEDY) · four-way verdict
  (proceed / modify / abandon / research more) · fresh context per seat
  per unit, non-negotiable (the recorded violation: 279 raw → 169
  substantive → 105 unique → zero of six units converged).
- **Tag semantics adapt per artifact type** — for a design review:
  SUBSTANTIVE = changes what a sourcer asks of a source or what an
  observation must capture; LINE = tunes a labelled parameter. The
  skill should take this mapping as a parameter alongside lenses ·
  rounds · bar.
- **Dual-family mode, grounded:** for plan review, cross-family
  agreement is judged at the finding level in consolidation — never
  computed with extraction statistics (Jaccard/claim-count instruments
  measure blind-extraction agreement, a different job; Ben's ruling).
  Same-model passes measure session variance and every same-model
  number is a floor. Cross-model remains never-run fleet-wide; it is
  only automatable where multi-vendor credentials exist (this
  workstation has Claude only — verified), but the prompts are
  deliberately self-contained and portable, so a manual second-family
  pass through another vendor's UI is legitimate.

## One conflict to resolve in RESEARCH.md

§7.7 currently describes the manuscript v2.0 seat semantics (Blue =
friendly reader, Green = methodologist). Ben's rulings supersede those
labels for the operative minimum: Blue answers Red only; Green is the
supported pro case. The manuscript's methodologist / friendly-reader /
editorial functions remain available as optional extension seats under
new labels (the method doc's §3 carries the collision table). RESEARCH.md
should adopt the function-registry framing rather than the v2.0 color
assignments.
